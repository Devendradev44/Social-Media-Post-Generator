📱 AI Social Media Post Generator

🔗 Live Demo: https://socialmediapostgeneratorr.netlify.app/

AI Social Media Post Generator is a web application that converts raw content into platform-specific social media posts using AI. Users can paste any text and instantly generate engaging posts tailored for different platforms like LinkedIn, Instagram, and Twitter/X.

AI tools like social media post generators help users quickly create engaging posts and save time on content creation.

🚀 Features

✨ Generate AI-powered social media posts

📱 Platform-specific posts for LinkedIn, Instagram, and Twitter/X

🧠 AI-based content generation using Google Gemini API

⚡ Fast post generation from raw text

🎨 Clean and responsive React UI

🔒 Secure API calls using Netlify Serverless Functions

📌 How It Works

Enter or paste your raw content

Select the social media platforms

Click Generate Posts

AI analyzes your content

Platform-specific posts are generated instantly

💡 Problem It Solves

Creating social media content for multiple platforms takes time and effort. AI-powered social media generators help automate this process by converting a single piece of content into multiple platform-optimized posts.

⚙️ Installation

Clone the repository

git clone https://github.com/Devendradev44/Social-Media-Post-Generator.git

Install dependencies

npm install

Run development server

npm run dev
🔐 Environment Variables

Create a .env file

GEMINI_API_KEY=your_api_key_here

For deployment, add the environment variable in Netlify Dashboard → Site Settings → Environment Variables.

🌍 Deployment

This project is deployed using Netlify.

Deployment steps:

npm run build

Netlify automatically builds and deploys the application.
